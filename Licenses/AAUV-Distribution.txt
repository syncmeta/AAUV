GNU General Public License, version 3 or any later version. The complete

The Mac sing-box executable is distributed under GPL-3.0-or-later, with
the same upstream notices. AAUV starts it as a separate process.

The matching AAUV source archive includes the application and extension
source, build scripts, fixed-version dependency sources, license notices,
and dependency inventory. The Mac package includes this archive alongside
AAUV.app.

The optional GitHub Copilot CLI runtime is distributed as unmodified
independent executables and libraries. Its own license is included as
copilot-cli-arm64-LICENSE and copilot-cli-x86_64-LICENSE in Mac builds that
contain the respective runtime. AAUV communicates with that runtime
through its separately launched bridge process. The Copilot Go SDK
license is included as copilot-sdk-LICENSE.

THIRD_PARTY.md and the remaining license files.
